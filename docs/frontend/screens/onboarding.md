# Onboarding / Welcome Screen

Layout
- Top: logo (left) + tenant branding (if present)
- Center: headline, short description, illustrative image (designer-created)
- Bottom: primary CTA (Get started), small secondary link (Sign in)

States
- Default: show CTA
- Returning user: show Sign in primary

Assets
- Illustration (SVG) — human-created
- Primary CTA uses `AppButton` primary style

Accessibility
- Headline should be H1; buttons with aria labels and sufficient contrast.
